# EVOL

Прототип сервиса доставки лакокрасочных покрытий. Чистые HTML, CSS и JS без сборки.

## Страницы
- `index.html` — старт (вход / регистрация)
- `login.html`, `register.html`, `address.html` — вход, регистрация, адрес доставки
- `catalog.html` — каталог с категориями и корзиной
- `account.html` — личный кабинет и история заказов

## Запуск
Нужен любой статический сервер (ES-модули и `fetch` не работают с `file://`):

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Данные
Товары лежат в `data/products.json` (необязательное поле `oldPrice` включает скидку). Корзина, заказы и профиль хранятся в `localStorage`. Бэкенда нет, пароли не проверяются и не сохраняются.
