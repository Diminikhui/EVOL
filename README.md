# EVOL

Прототип сервиса доставки лакокрасочных покрытий. Чистые HTML, CSS и JS без сборки.

## Страницы
- `index.html` — старт (вход / регистрация)
- `login.html`, `register.html`, `address.html` — вход, регистрация, адрес доставки
- `admin.html` — админка: товары, цены, фото, остатки (нужен сервер)
- `catalog.html` — каталог с категориями и корзиной
- `checkout.html` — оформление заказа с адресом
- `track.html` — отслеживание заказа по этапам
- `account.html` — личный кабинет: заказы, бонусы, избранное, адреса, уведомления

## Запуск

**С сервером** (каталог из базы, админка, остатки). Нужен Node.js 22.5 или новее, зависимостей нет:

```bash
ADMIN_PASSWORD='ваш-пароль' npm start
```

Откройте http://localhost:8000. Админка: http://localhost:8000/admin.html (логин `admin`). Если не задать `ADMIN_PASSWORD`, при первом запуске пароль будет создан случайным и показан один раз в консоли.

Переменные окружения: `PORT`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `SESSION_SECRET` (чтобы сессии переживали перезапуск), `DB_FILE` (по умолчанию `data/evol.db`).

**Без сервера** (только просмотр, как на GitHub Pages): подойдёт любой статический сервер. Каталог тогда читается из `data/products.json`, админки и остатков нет.

```bash
python3 -m http.server 8000
```

Тесты сервера: `npm test`.

## Данные
Промокоды лежат в `data/promos.json` (типы: `percent`, `fixed`, `delivery`). Бонусы: 5% за доставленный заказ, оплатить ими можно до 30% заказа.

Уведомления о статусе (`js/notify.js`, `sw.js`) приходят, пока сайт открыт в браузере: для настоящего push нужен сервер.

Товары хранятся в базе SQLite (`data/evol.db`, создаётся при первом запуске из `data/products.json`). Фото из админки сохраняются в `uploads/`. Заказы, корзина, избранное и бонусы пока остаются в браузере покупателя, на сервер они переедут следующим шагом.

В файле `data/products.json` необязательное поле `oldPrice` включает скидку. Без сервера корзина, заказы и профиль хранятся в `localStorage`, а статус заказа вычисляется по времени с момента оформления (`js/status.js`, сроки ускорены: весь путь занимает 5 минут). Пароли покупателей не проверяются и не сохраняются.
