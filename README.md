# EVOL

Прототип сервиса доставки лакокрасочных покрытий. Чистые HTML, CSS и JS без сборки.

## Страницы
- `index.html` — старт (вход / регистрация)
- `login.html`, `register.html`, `address.html` — вход, регистрация, адрес доставки
- `catalog.html` — каталог с категориями и корзиной
- `checkout.html` — оформление заказа с адресом
- `track.html` — отслеживание заказа по этапам
- `account.html` — личный кабинет: заказы, бонусы, избранное, адреса, уведомления

## Запуск
Нужен любой статический сервер (ES-модули и `fetch` не работают с `file://`):

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.

## Данные
Промокоды лежат в `data/promos.json` (типы: `percent`, `fixed`, `delivery`). Бонусы: 5% за доставленный заказ, оплатить ими можно до 30% заказа.

Уведомления о статусе (`js/notify.js`, `sw.js`) приходят, пока сайт открыт в браузере: для настоящего push нужен сервер.

Товары лежат в `data/products.json` (необязательное поле `oldPrice` включает скидку). Корзина, заказы и профиль хранятся в `localStorage`. Статус заказа вычисляется по времени с момента оформления (`js/status.js`, сроки ускорены: весь путь занимает 5 минут). Бэкенда нет, пароли не проверяются и не сохраняются.
