# EVOL

Прототип сервиса доставки лакокрасочных покрытий. Чистые HTML, CSS и JS без сборки.

## Страницы
- `index.html` — старт (вход / регистрация)
- `login.html`, `register.html`, `address.html` — вход, регистрация, адрес доставки
- `admin.html` — админка: товары, цены, фото, остатки, сотрудники (нужен сервер)
- `staff.html` — панель заказов для склада и курьеров (нужен сервер)
- `catalog.html` — каталог с категориями и корзиной
- `checkout.html` — оформление заказа с адресом
- `track.html` — отслеживание заказа по этапам
- `account.html` — личный кабинет: заказы, бонусы, избранное, адреса, уведомления

## Запуск

**С сервером** (каталог из базы, админка, остатки). Нужен Node.js 22.5 или новее, зависимостей нет:

```bash
ADMIN_PASSWORD='ваш-пароль' npm start
```

Откройте http://localhost:8000. Админка: http://localhost:8000/admin.html (логин `admin`). Если не задать `ADMIN_PASSWORD`, при первом запуске пароль будет создан случайным и показан один раз в консоли.

Переменные окружения: `PORT`, `ADMIN_LOGIN`, `ADMIN_PASSWORD`, `SESSION_SECRET` (чтобы сессии переживали перезапуск), `DB_FILE` (по умолчанию `data/evol.db`).

**Без сервера** (только просмотр, как на GitHub Pages): подойдёт любой статический сервер. Каталог тогда читается из `data/products.json`, админки и остатков нет.

```bash
python3 -m http.server 8000
```

Тесты сервера: `npm test`.

## Данные
Промокоды лежат в `data/promos.json` (типы: `percent`, `fixed`, `delivery`). Бонусы: 5% за доставленный заказ, оплатить ими можно до 30% заказа.

Уведомления о статусе (`js/notify.js`, `sw.js`) приходят, пока сайт открыт в браузере: для push на закрытый сайт нужна отдельная серверная часть (Web Push).

Каталог из `data/products.json` — 100 товаров в 10 категориях (названия брендов вымышленные, картинки-иллюстрации лежат в `img/catalog/`). Товары попадают в базу только при её создании: чтобы подтянуть обновлённый список в уже существующую базу, остановите сервер и удалите `data/evol.db` (вместе с ней удалятся заказы и пользователи), либо правьте товары в админке.

Всё хранится в базе SQLite (`data/evol.db`, создаётся при первом запуске; товары берутся из `data/products.json`). Фото из админки лежат в `uploads/`.

**Роли.** Покупатель регистрируется по телефону и паролю. Сотрудников (склад, курьеры, администраторов) создаёт администратор в админке.

**Путь заказа.** Принят → Собирается → В пути → Доставлен (или Отменён):
- склад: «Начать сборку», «Передать курьеру», отмена;
- курьер: видит заказы «В пути», отмечает «Доставлен»;
- покупатель: отслеживает и может отменить, пока заказ не в пути.

Цены, скидки по промокодам и бонусы всегда считает сервер, а не браузер. Остаток списывается при заказе и возвращается при отмене. Бонусы начисляются после доставки.

Пока в браузере покупателя остаются избранное, сохранённые адреса и корзина.

В файле `data/products.json` необязательное поле `oldPrice` включает скидку. Без сервера работает демо-режим: корзина, заказы и профиль хранятся в `localStorage`, а статус заказа вычисляется по времени (`js/status.js`, весь путь занимает 5 минут). Входа в этом режиме нет.
